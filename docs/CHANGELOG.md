# NovelCat 修改日志

## 2026-09-29

### 按反馈调整对话弹层

- 历史对话改为按钮下方的小浮窗，独立滚动、实色遮挡底层文字，宽高跟随侧栏及可见窗口；侧栏因响应式布局隐藏时同步关闭浮窗。
- 对话设置改为居中设置页，页面背景虚化并变暗，聊天及未发送内容始终保留。设置、参考文档和确认框共用顶层模态基础组件，支持 Esc 逐层关闭、焦点归位和点击背景关闭。
- 统一主题色、深色滚动条、输入框和按钮对比度；尊重系统减少透明效果的偏好。
- 验证桌面 1440px、窄屏 390px、搜索/切换、嵌套弹窗返回和输入保留；新增 4 项浮窗定位测试。未修改导出逻辑，也未发送 AI 请求或改动小说正文。

### 写作界面与对话交互

- 根据用户反馈恢复背景模式的磨砂稿纸：浅色模式 50% 遮罩，深色模式 70%，14px 模糊；正文加深/提亮保持可读。底部可切换“背景磨砂 / 清晰纸张”，本机记住选择，清晰模式仍遵循原纸张不透明度设置。不修改用户背景图片或服务端设置。
- AI 侧栏重新分成聊天、历史对话和对话设置三个内部视图。删除全页透明菜单遮罩、固定坐标小下拉菜单和常驻标签堆叠；人格改为标准选择控件，参考资料及详细分析集中到设置。
- 历史列表操作不再只在鼠标悬浮时出现；常用操作增加文字和点击区域。输入框整合发送/停止按钮，引用稿件改为输入区上方的引用条，复制与局部修改能力保留。
- 资料选择与删除确认统一使用原生顶层对话框，避免被侧栏的磨砂/变换容器限制定位；支持焦点限制、Esc 取消及关闭后焦点归位。
- 验证：前端 lint、生产构建通过；浏览器检查 1440px 桌面及 390px 窄屏、历史/设置一次点击切换、引用及输入在视图切换后保留、资料弹窗定位与 Esc/焦点恢复、磨砂/清晰切换。本轮未发起 AI 请求，也未修改小说正文。

## 2026-09-21

### AI 服务配置

- 设置页改为用户级 AI 服务配置列表，可保存多条 DeepSeek、OpenAI 和 OpenAI 兼容服务，并独立设置名称、Base URL、模型与 API Key。
- 新增模型列表读取、连接测试、切换当前服务、删除密钥和删除配置；模型列表会直接显示为可选项，新配置保存前也能按当前 Base URL 和 API Key 获取；密钥只返回保存状态与末尾提示，不返回明文或密文。
- 新建服务不再写死容易过期的模型名称；环境默认的 DeepSeek 模型更新为 `deepseek-flash`，已有服务仍由用户从实时列表确认后切换。
- AI 对话、WebSocket 与健康检查统一使用当前服务配置，修复不同供应商环境变量导致健康状态误报的问题。
- 旧版 DeepSeek/OpenAI 密钥自动迁移，保留环境变量回退；服务配置继续按用户隔离。

### AI 对话重构

- AI 保留对话式入口，但取消写入、追加、替换正文和重新生成等正文操作；每条完成回复只保留一个“复制内容”动作。
- 新增严格的 `reply + copy_text` 输出协议：说明与最终可用内容分离，可复制区域会清理代码围栏和旧版分隔格式，并兼容历史对话。
- 每轮对话由后端固定准备“全书理解上下文”，不再依赖模型决定是否读取作品：小型作品注入全书正文，长篇作品注入完整章节摘要索引、当前与相邻章节正文和本轮相关原文。
- 当前编辑器的未保存内容优先于数据库旧正文；前端明确显示“每轮读取全书”，Agent 过程记录本轮上下文覆盖范围。
- 近期对话会携带 AI 上一轮的可复制内容，支持“把刚才那段再改一下”等连续指令；提及旧讨论时按书召回相关历史对话。
- 书级滚动记忆区分正文事实、已确认决定、未确认想法、未回收线索和写作偏好，避免把 AI 候选方案自动当成既定设定。
- 增加上下文预算约束，为模型输出预留空间；补充全书上下文、未保存正文覆盖、长篇降级和结构化输出解析测试。

## 2026-09-20

### 功能新增

- AI 外部资料检索修复：选中的知识库文档会按其真实 `project_id` 路由到对应 Chroma 集合；未指定文档时同时兼容书籍资料与全局资料，修复“已选资料但 AI 搜不到”的问题。
- AI 人格切换修复：AI 面板改用全局写作人格的真实启用接口，与设置页和 `AIService` 的读取来源保持一致。
- AI 生成支持手动停止：停止后保留并持久化已生成内容，同时正确结束流式状态与 Agent 时间线。
- AI 输入兼容中文输入法组合态，避免选字时按回车误发送；新对话增加基于当前章节的快捷写作问题。
- 写作编辑器新增“光标跟随”模式（`Ctrl+Shift+L`），输入时将光标维持在舒适阅读区域，并记住用户选择。
- 写作编辑器新增专注模式（`Ctrl+Shift+F`），可同时收起目录与 AI 面板；再次触发即可恢复。
- 编辑器字号现在读取设置页的 `font_size`；粘贴纯文本转段落时增加 HTML 转义，避免特殊字符破坏正文结构。
- AI 正文结果支持“追加正文”与“替换正文”；替换前二次确认，保存后仍可通过章节版本历史恢复。

## 2026-08-14

### 功能新增

- 章节类型化：`Chapter.kind` 支持 `outline / prose / note / reference`，默认 `prose`。
  - 幂等迁移，旧章节自动归为正文。
  - 章节列表按类型分组展示，支持组内拖动。
  - 章节类型可经行内自定义下拉修改，主题化样式与既有控件一致。
  - AI 工具按类型过滤：`get_book_outline` 只读大纲，`get_recent_chapters` / 附近摘要只读正文，`search_my_chapters` 全类型并标注来源。
  - 新增 `get_book_structure` 工具，返回全书分组结构。
- AI 自适应分层输出：后端按意图给出输出形状提示，复杂任务可用 `## 标题` 分段；前端解析后渲染为分区卡片，小问题保持普通文本。
- 会话绑定书籍：`Conversation` 增加 `book_id`、`archived`、`token_estimate`。
  - 后端支持按书籍列出/过滤、归档、恢复。
  - 前端切书自动切换对话列表并清除旧书草稿，新对话自动绑定当前书。
  - 数据迁移：启动时把历史遗留的 `book_id=NULL` 对话自动归入该用户的第一本书，避免重启后对话“消失”；前端打开无主对话时也会自动绑定当前书。
- 会话完整转录：AI 消息记录工具/上下文步骤（读取章节、检索、大纲等），恢复会话后可在消息下方展开查看“Agent 过程”。
- 会话面板增强：对话下拉支持搜索、显示已归档对话、单条归档/恢复；打开已归档对话会自动取消归档。
- 记忆与上下文：
  - 新增本地 token 估算器（中文按字符、其他文本按 4 字符/token），对话保存时自动计算 `token_estimate`。
  - 对话历史组装改为 token 预算驱动：先保留最近若干条，再在预算内向后扩展，替代固定 16 条裁剪。
  - 书级滚动记忆：每轮对话结束后后台增量更新 `MemorySummary`（前情提要/人物状态/未回收线索/设定要点/文风笔记），按书籍隔离。
- 新增 `search_chat_history` 工具，可从完整对话历史中按关键词召回旧内容。
- Agent 工具时间线：后端每个规划/工具/生成步骤携带参数、结果摘要、耗时（`elapsed_ms`）；前端升级为可展开的时间线面板，恢复会话后也能查看。
- 流式输出再修复：前端恢复逐 token `flushSync` 强制渲染，避免整段闪现。
- AI 提速：
  - embedding 模型改为按需加载（`ensure_ready`），首次聊天/保存不再被 torch 冷启动卡住，失败后缓存结果避免重复尝试。
  - 工具决策从最多 3 轮串行改为单轮，模型可在同一轮返回多个工具调用。
- 人格预设选择修复：前端选择/取消预设时真正调用后端 enable/disable 接口，之前 `preset_id` 发送后被后端忽略。
- 切书/新会话时主动断开 WebSocket，避免旧流继续写入新会话。
- AI 面板顶部显示当前会话估算 token 数。
- 章节保存链路修复：主编辑器使用的 `books/{book_id}/chapters/{id}` 创建/更新接口现在也会触发摘要生成与章节向量重索引（之前只更新数据库和文件，Chroma 里一直是旧内容）。
- 设定一致性：大纲/笔记/资料类章节内容修改后，后台会把变更合并进该书滚动记忆，替换过时条目而不是追加重复文本；章节向量采用删除旧分块后重插，不保留旧版重复内容。
- 保存竞态修复：对话持久化改为串行队列，始终保存最新快照，避免快速连续对话时请求乱序覆盖丢消息；消息持久化已从 React setState updater 中移出，避免开发模式重复保存。
- AI 窗口空状态：未选择对话时显示“还没有选择对话”落地页，提供新建/选择历史对话入口，不再每次默认创建一个空白对话。
- 新增 `scripts/reset_password.py`，可本地重置账号密码。

### 体验修复

- 流式输出：前端改为 50ms / 换行 / 64 字触发 `flushSync` 渲染，恢复逐字可见。
- 工具协议泄漏：后端剥离泄漏的工具协议，首块整块为协议时输出兜底文案。
- 章节类型原生下拉框替换为自定义主题化菜单，避免白底与暗色主题冲突。
